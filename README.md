# AJ139 Monitor

App para Windows que mostra a bateria e configura o mouse sem fio **AJAZZ AJ139 V2 MC**, sem precisar abrir o configurador web.

## Download

**[Baixar AJ139Monitor.exe (versão mais recente)](https://github.com/patgithub23/aj139-monitor-releases/releases/latest/download/AJ139Monitor.exe)**

Execute o exe; o app fica no ícone da bandeja, ao lado do relógio. Se o Windows mostrar o aviso do SmartScreen, clique em *Mais informações → Executar assim mesmo*.

## Funções

- **Status:** bateria, carregamento, conexão, firmware, DPI e polling rate.
- **Ajustes:** níveis de DPI, polling rate, iluminação, scroll, sensor e tempo para dormir.
- **Botões:** remapeia os botões para ações do mouse, multimídia, teclas ou macros.
- **Macros:** grava teclas e cliques com os tempos e salva na memória do mouse.
- **Alarme de bateria:** aviso com som e janela quando a bateria fica fraca.
- **Overlay:** mostra a porcentagem por cima do jogo (`Ctrl+Shift+B` liga e desliga).
- **Bandeja:** ícone com a porcentagem atual e opção de iniciar com o Windows.

O overlay não aparece em jogos em tela cheia exclusiva; use o modo janela sem bordas.

Projeto independente, sem ligação com a AJAZZ.
